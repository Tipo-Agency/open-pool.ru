# Метрика OpenPool, 18 октября 2026

По поручению владельца создан агентский счётчик 113666777, имя «Открытый Бассейн | open-pool.ru», аккаунт tipaagentstvo, домен open-pool.ru, RUB, UTC+10. Вебвизор включён. Принятие соглашения отдельно подтверждено пользователем.

Прежний счётчик 112335661 отвечает 403 для агентства. Его отсутствие в списке не доказывает удаления или потери истории. Новый счётчик собирает данные после установки; прошлые записи в него не переносятся.

`YANDEX_METRIKA_IDS` временно содержит оба номера. Инициализация и события отправляются один раз в каждый счётчик. Это сохраняет прежние сигналы для существующих зависимостей рекламы и Calltouch до отдельной проверки миграции. Числа двух счётчиков нельзя складывать как уникальные обращения.

Основная цель: точное совпадение `lead_submit` (цель 672421307). В коде она отправляется только после успешного ответа `/api/leads`, повторные заявки исключены. Событие `lead_submit_success` описывает ту же заявку и не должно становиться второй основной конверсией.

Дополнительные события: `booking_open`, `lead_form_start`, `lead_submit_attempt`, `lead_submit_error`, `phone_click`, `messenger_click`, `price_view_click`, `article_service_click`. Клик по телефону не подтверждает состоявшийся звонок, переход в мессенджер не подтверждает диалог.

Откат подключения: вернуть прежнюю версию tracking.tsx, analytics-client.ts и lead-client.ts либо предыдущее production release. Старый счётчик и цели не удалять. После проверки новых сигналов отдельно сверить счётчик и выбранные цели активных кампаний Директа.

Проверка браузером выявила автофокус при открытии формы. `lead_form_start` перенесён с focus на input: открытие формы учитывается отдельно, начало заполнения означает фактический ввод.
