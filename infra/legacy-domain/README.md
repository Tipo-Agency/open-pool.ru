# Старый технический домен бассейна

`pool.tipa.uz/*` постоянно перенаправляется на соответствующий путь `https://open-pool.ru/*`. Путь, кодирование и query string сохраняются, включая рекламные метки. Другие домены этот Worker обслуживать не должен.

Ранее техническая копия отвечала 200 и разрешала индексацию. Canonical был правильным, но копия оставалась доступна. Пользователь подтвердил, что этот адрес больше не нужен.

Развёртывание из корня репозитория:

```sh
npx wrangler whoami
npx wrangler deploy --config infra/legacy-domain/wrangler.jsonc
```

Откат: отключить только маршрут `pool.tipa.uz/*` в зоне `tipa.uz`. До этого изменения Workers routes в зоне были пустыми. Основной сервер и DNS-записи этот выпуск не меняет. DNS и старую публикацию сохраняем для работы постоянного перенаправления.

Проверка: главная, `/kontakty`, статья и рекламный URL с UTM должны отвечать 301 с соответствующим Location. Конечный существующий URL основного сайта должен возвращать 200.
